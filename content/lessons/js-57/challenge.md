## Практика FocusBoard

Створи `parseTaskFile(raw)` із наявним валідатором і `makeTaskBlob(tasks)` для JSON версії 2. Додай `countImportedTasks(raw)`, що повертає довжину коректного списку або -1.

Додай поле вибору JSON і кнопку «Експорт задач». Імпорт має обмежувати файл 64 КіБ, перевіряти записи й зберігати поточний список при помилці. Після успішної заміни онови наступний ID. Експорт показує JSON у полі для копіювання та створює посилання для збереження файла у звичайному запуску.
