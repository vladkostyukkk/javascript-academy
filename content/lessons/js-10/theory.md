## Збираємо дані FocusBoard

У цьому уроці немає нового синтаксису. Ми поєднуємо змінні, арифметику, порівняння, перетворення та шаблонні рядки в один текстовий preview.

## Порядок роботи

Спочатку підготуй числа, потім обчисли похідні значення і лише після цього створи текст. Не перетворюй число на рядок до завершення арифметики.

```js
const planned = 15;
const available = Number("20");
const spare = available - planned;
const summary = `Запас: ${spare} хв`;
```

Для рівних значень запас буде 0, а коли доступний час менший — від’ємним. Це результат обчислення, який не слід приховувати або замінювати готовим текстом.

## Дані та відображення

Попередня картка описує задачу на 25 хвилин. Нове поле parsedMinutes моделює доступні 30 хвилин для цього preview. Порівняння з timeLimit виконуємо окремо: запас часу й перевищення ліміту відповідають на різні запитання. Булеве true в тексті поки залишаємо технічним статусом; людські назви станів з’являться в модулі умов.

## Самоперевірка

Чи береться текст із cardText? Чи запас обчислюється відніманням? Чи прапорець отримано порівнянням? Чи використані числові parsedMinutes, а не рядкові minutesInput? Перевір також роздільники й пробіли.
