## Одна картка, один підпис

У FocusBoard кожна задача зберігає назву, тривалість та інші дані. Щоб отримати з них підписи для всіх карток, можна перетворити один масив на інший через `map`.

`map` приймає функцію, яку викликає для кожного елемента. Таку функцію називають callback. Значення, яке вона повертає, потрапляє в новий масив на місце відповідного елемента. Для звичайного списку результат має ту саму кількість елементів у тому самому порядку.

```js
const prices = [10, 0, 25];
const labels = prices.map((price) => `${price} грн`);

console.log(labels); // ["10 грн", "0 грн", "25 грн"]
console.log(prices); // [10, 0, 25]
```

## Передай функцію

Якщо функція вже існує й їй потрібен тільки перший аргумент, можеш передати її за ім’ям. У прикладі `addUnit` отримує поточне значення щоразу, коли `map` її викликає.

```js
function addUnit(number) {
  return `${number} кг`;
}

const weights = [3, 5];
const labels = weights.map(addUnit);

console.log(labels); // ["3 кг", "5 кг"]
```

Запис `weights.map(addUnit())` спочатку викличе `addUnit` без числа й передасть у `map` отриманий рядок. Метод очікує функцію, отже потрібне її ім’я без дужок.

## Збережи результат

У callback зі стрілковою функцією та фігурними дужками потрібно явно повернути значення через `return`. Якщо callback завершується без `return`, на місці перетвореного елемента опиниться `undefined`.

Що поверне `[].map(addUnit)`? Скільки разів викличеться `addUnit` для `[3, 3]`?
