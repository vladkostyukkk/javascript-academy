## Редагування й видалення

Один делегований обробник може обслуговувати кілька кнопок. `data-action` визначає дію, а `data-task-id` на картці визначає запис. Після зміни запису знову відобрази дані.

```js
const index = list.findIndex((item) => item.id === selectedId);
if (index !== -1) {
  list.splice(index, 1);
}
```

`findIndex` повертає позицію збігу або `-1`. Позиція в масиві може змінитися після видалення, а ID лишається сталим. Під час редагування достатньо змінити властивість `title` знайденої задачі. Решта полів і її позиція збережуться.
