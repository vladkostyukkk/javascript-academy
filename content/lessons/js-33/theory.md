## Рендеринг списку

У js-32 один виклик `createTaskCard(tasks[0])` показував тільки першу задачу. Щоб відобразити колекцію, передай у функцію кожний елемент через знайомий цикл `for...of`. Такий перехід від даних до видимих елементів називають рендерингом.

```js
function renderLabels(container, labels) {
  container.textContent = "";
  for (const label of labels) {
    const item = document.createElement("p");
    item.textContent = label;
    container.append(item);
  }
}
```

Спочатку очищаємо контейнер. Якщо викликати функцію ще раз, старі елементи поступляться місцем новим. Без очищення картки додаватимуться повторно. Для порожнього масиву тіло циклу не виконується, тому після очищення контейнер лишається порожнім.

Виклик `append()` додає елемент у кінець контейнера. Порядок карток збігається з порядком задач, відібраних для показу.
