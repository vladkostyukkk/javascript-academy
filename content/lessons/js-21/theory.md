## Список в одній змінній

До цього FocusBoard зберігав окрему назву задачі. Щоб тримати кілька назв разом, створи **масив**. Значення в масиві називаються елементами. Масив зберігає їх у заданому порядку. Запиши елементи через кому в квадратних дужках.

```js
const firstStop = "Варшава";
const stops = [firstStop, "Лодзь", "Познань"];

console.log(stops[0]); // Варшава
console.log(stops[1]); // Лодзь
console.log(stops.length); // 3
```

Перший елемент має **індекс** `0`, другий — `1`. Запис `stops[1]` читає значення за індексом `1`. Властивість `length` показує кількість елементів.

## Довжина і межі

Коли масив має хоча б один елемент, останній індекс дорівнює `length - 1`. Індекс, що дорівнює довжині, уже стоїть за межами списку. Читання за таким індексом дає `undefined`. Порожній масив `[]` має довжину `0`, тому читання за індексом `0` теж дає `undefined`.

```js
const breaks = ["Чай", "Прогулянка"];
const lastIndex = breaks.length - 1;

console.log(breaks[lastIndex]); // Прогулянка
console.log(breaks[breaks.length] === undefined); // true

const emptyBreaks = [];
console.log(emptyBreaks.length); // 0
console.log(emptyBreaks[0]); // undefined
```

`undefined` — значення без лапок. Рядок `"undefined"` містить текст і не пройде порівняння `=== undefined`.

## Індекс із параметра

Між квадратними дужками можна записати змінну. Це дає змогу читати різні позиції однією функцією.

```js
function readStop(route, position) {
  return route[position];
}

console.log(readStop(["Київ", "Львів"], 1)); // Львів
console.log(readStop(["Ужгород"], 0)); // Ужгород
```

Перевір себе. Обидва приклади викликають одну функцію. Яке значення вона поверне для `readStop(["Харків"], 1)`? У масиві з однієї назви є тільки індекс `0`, тому результат — `undefined`.
