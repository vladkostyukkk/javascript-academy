## Незмінні оновлення

Незмінне оновлення створює новий масив. Для зміненої задачі створюємо новий об’єкт, а решту об’єктів можна використати повторно.

```js
const updated = list.map((task) =>
  task.id === id ? { ...task, title: "Новий план" } : task,
);
```

Попередній масив і його записи мають лишитися такими, як були. Це потрібно для історії та скасування. Для додавання підходить spread, для видалення — `filter`.
