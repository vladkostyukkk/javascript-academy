## Перебір значень через for...of

FocusBoard може зібрати окремі булеві прапорці в масив. Кожен прапорець позначає, чи виконана задача. Щоб перевірити кожен прапорець, використай цикл. Одне виконання тіла циклу називають **ітерацією**.

```js
const checkedDoors = [false, true, true];
let checkedCount = 0;

for (const isChecked of checkedDoors) {
  if (isChecked) {
    checkedCount = checkedCount + 1;
  }
}

console.log(checkedCount); // 2
```

`for...of` дає наступне значення масиву на кожній ітерації. Спочатку `isChecked` дорівнює `false`, потім двічі `true`. Лічильник оголошено перед циклом, щоб зберегти підрахунок між ітераціями. Для порожнього масиву тіло циклу не виконається, тому лічильник залишиться нульовим.

## Перебір індексів через for

Коли потрібна позиція елемента, зручно тримати поточний індекс. У звичайному `for` у дужках записано три частини, розділені крапками з комою.

```js
const stops = ["Київ", "Львів"];

for (let index = 0; index < stops.length; index = index + 1) {
  console.log(`${index}: ${stops[index]}`);
}
```

1. `let index = 0` задає початок і виконується один раз.
2. `index < stops.length` перевіряється перед кожною ітерацією. Якщо умова хибна, цикл зупиняється.
3. `index = index + 1` виконується після тіла циклу й готує наступний індекс.

Для масиву з двох елементів тіло виконається з індексами `0` і `1`. Умова `index <= stops.length` дала б ще одну зайву ітерацію з індексом `2`.

## Перший збіг

У функції `return` завершує і цикл, і виклик функції. Якщо потрібен індекс першого збігу, повертай його одразу після перевірки. Після циклу можна повернути `-1`, щоб позначити, що збігу не знайдено. Нуль означає дійсний індекс першого елемента.

Перевір себе. Для прапорців `[false, true, true]` підрахунок дасть `2`, а пошук першого збігу поверне індекс `1`.
