## Вибір за точним значенням

У Kanban-дошці кожен статус відповідає колонці. Коли порівнюєш одне значення з кількома відомими варіантами, `switch` допомагає записати відповідності в одному блоці.

Наприклад, FocusBoard може показувати коротке повідомлення про активний фільтр.

```js
const filter = "важливі";
let caption = "";

switch (filter) {
  case "усі":
    caption = "Усі задачі";
    break;
  case "важливі":
    caption = "Важливі задачі";
    break;
  default:
    caption = "Невідомий фільтр";
}

console.log(caption);
```

У дужках після `switch` стоїть значення, яке порівнюємо. Кожен `case` задає точний збіг, як `===`. Для рядків має значення регістр і пробіли. У прикладі збігається другий `case`, після присвоєння `break` завершує `switch`, і консоль показує «Важливі задачі».

## Що роблять break і default

Якщо після збігу пропустити `break`, JavaScript продовжить виконувати рядки наступної гілки. Прибери `break` з гілки «важливі» у прикладі. Тепер присвоєння в `default` перезапише `caption`.

Коли жоден `case` не збігається, виконання починається з `default`. Він стоїть останнім, тож після нього немає наступної гілки.

Перед практикою подумай, що виведе приклад для `"ВАЖЛИВІ"`. Потім простеж, що станеться для `"усі"`, якщо забрати перший `break`.
