## Фільтри

Фільтр задає, які записи показати зараз. Масив `tasks` зберігає всі записи. Метод `filter` повертає підмасив для поточного вигляду.

```js
const active = tasks.filter((task) => task.status !== "Готово");
```

Збережи ключ обраної кнопки в окремій змінній. Після зміни фільтра або задачі обчисли видимий список знову. Наприклад, завершена задача в режимі «Активні» має зникнути з перегляду, але залишитися доступною в режимі «Усі». Атрибут `aria-pressed` допомагає повідомити, який режим активний.
