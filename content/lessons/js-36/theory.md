## Валідація інтерфейсу

Форма має пояснювати, чому дія не виконалася. Попередня функція `validateTitle` повертає повідомлення для некоректної назви або `null` для коректної.

```js
const title = field.value.trim();
const error = validateTitle(title);
message.textContent = error ?? "";
if (error) {
  field.focus();
  return;
}
```

`trim()` прибирає пробіли з початку й кінця. Запис повідомлення перед умовою дає два результати: помилка з’являється для пустої назви й очищається після виправлення. Ранній `return` зупиняє обробник до зміни масиву. `aria-describedby` пов’язує поле з поясненням, а `aria-live="polite"` повідомляє про його зміну.
