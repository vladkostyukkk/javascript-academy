## Дані першої задачі

FocusBoard уже має appName. Тепер збережемо назву задачі, пріоритет і тривалість. Продовжуй код попереднього уроку.

## const — початкове значення

const оголошує ім’я, якому не можна повторно присвоїти інше значення. Текст записують у лапках, число — без лапок.

```js
const exampleTitle = "Прочитати розділ";
const exampleMinutes = 15;
```

15 — число, а "15" — текст. Обчислення вивчатимемо пізніше.

## let — значення можна змінити

```js
let examplePriority = 1;
examplePriority = 3;
console.log(examplePriority);
```

Консоль покаже 3. Під час зміни не повторюємо let: ім’я вже оголошене. Знак = означає присвоєння значення.

## Типові помилки

- Повторне let для того самого імені в одному місці програми спричиняє помилку оголошення.
- Спроба присвоїти інше значення змінній const спричиняє помилку виконання.
- "25" — текст; 25 — число.
- taskTitle і tasktitle — різні імена: регістр важливий.
