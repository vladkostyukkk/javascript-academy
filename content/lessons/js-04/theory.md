## Скільки часу потрібно на справи

У FocusBoard вже є minutes — тривалість першої задачі. Додамо тривалість другої та загальну кількість хвилин. Поки це числові дані в коді; видимий список задач з’явиться пізніше.

## Число записують без лапок

~~~js
const readingMinutes = 20;
const breakMinutes = 5;
const plannedMinutes = readingMinutes + breakMinutes;
console.log(plannedMinutes);
~~~

Консоль покаже 25. Оператор + отримує два числа й додає їх. Початкові змінні залишаються незмінними. Для результату, який не переприсвоюємо, підходить const.

JavaScript підтримує цілі числа та дроби. Десятковий роздільник у коді — крапка: 2.5, не кома. Нуль також є числом: 20 + 0 дає 20. Для тривалості реальної справи обираємо невід’ємні значення; мінус перед числом робить його від’ємним і може зменшити суму.

## Той самий +, різні значення

У попередньому уроці + об’єднував текст. Якщо хоча б один операнд є рядком, цей оператор об’єднує текст замість додавання чисел.

~~~js
console.log(20 + 5);
console.log("20" + "5");
console.log(20 + "5");
~~~

Результати: число 25, рядок 205 і знову рядок 205. Лапки змінюють тип значення, навіть якщо всередині лише цифри. Не додавай слово «хв» до числової змінної: одиниці вимірювання пояснюємо назвою та інтерфейсом. Перетворення введеного тексту на число вивчатимемо окремо.

## Обчислення зі змінних

Вираз readingMinutes + breakMinutes використовує їхні значення в момент виконання. Запис лише готового результату 25 не описує зв’язок між тривалостями. Обчислена const не є формулою таблиці: вона не перераховується автоматично, якщо пізніше зміниться інша змінна.

## Типові помилки й самоперевірка

- "15" — текст, а 15 — число.
- -15 зменшує суму; це не тривалість другої справи.
- Порожній рядок "" не означає числовий нуль.
- Числа з дробовою частиною записуй із крапкою.
