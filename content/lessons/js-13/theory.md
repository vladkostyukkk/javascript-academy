## Кілька умов одночасно

Коли рішення залежить від кількох ознак, можна поєднати їх в один вираз. Для булевих значень діють такі правила.

- `!` змінює `true` на `false`, а `false` на `true`.
- `&&` дає `true`, коли обидві умови істинні.
- `||` дає `true`, коли хоча б одна умова істинна. Якщо істинні обидві, результат також `true`.

Наприклад, надішли нагадування, якщо його ще не надсилали й задача або на сьогодні, або термінова.

```js
const alreadySent = false;
const daysLeft = 1;
const isUrgent = true;
const shouldRemind = !alreadySent && (daysLeft === 0 || isUrgent);

console.log(shouldRemind);
```

Тут `!alreadySent` дорівнює `true`. У дужках порівняння дає `false`, а `isUrgent` дорівнює `true`, тож результат `||` істинний. Обидві частини `&&` істинні, тому `shouldRemind` дорівнює `true`.

## Дужки визначають правило

Оператори `!` і `&&` мають вищий пріоритет за `||`. Прибери дужки, і вираз прочитається як `(!alreadySent && daysLeft === 0) || isUrgent`. Тоді термінова задача знову отримає нагадування, навіть якщо його вже надсилали. В оригінальному виразі `!alreadySent` обов’язкове для обох альтернатив у дужках.

Перед практикою передбач результат, якщо `alreadySent` дорівнює `true`, а `isUrgent` залишається `true`. Потім зміни `alreadySent` на `false`, `isUrgent` на `false` і `daysLeft` на `0`.
