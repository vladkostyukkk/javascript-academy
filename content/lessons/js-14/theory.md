## Вираз для вибору значення

`if / else` зручно читати, коли кожна гілка виконує окремі дії. Якщо потрібно лише вибрати одне з двох коротких значень, тернарний оператор дає готовий результат для присвоєння.

```js
const hasDeadline = true;
const deadlineLabel = hasDeadline ? "Є термін" : "Без терміну";

console.log(deadlineLabel);
```

Прочитай вираз зліва направо. Перед `?` стоїть умова. Між `?` та `:` стоїть результат для `true`, а після `:` — результат для `false`. JavaScript обчислює лише обрану частину. У прикладі змінна `deadlineLabel` отримує «Є термін». Підстав `false`, щоб отримати «Без терміну».

## Коли читабельніше залишити блоки

У попередніх уроках ми застосовували умови і для трьох статусів, і для поєднання кількох правил. Тернарний оператор добре читається, коли є один вибір між двома короткими значеннями. Якщо треба виконати кілька дій або розрізнити три статуси, блоки допомагають побачити правила окремо.

Перед практикою визнач, що покаже `const iconText = hasDeadline ? "Календар" : "Нотатка";`, якщо `hasDeadline` дорівнює `false`.
