## Promise

Promise представляє результат, який стане доступним пізніше. Функція `resolve` завершує Promise успішно, а `then` отримує результат після завершення.

```js
const work = new Promise((resolve) => {
  setTimeout(() => resolve("готово"), 80);
});
work.then((message) => console.log(message));
```

Поки триває затримка, сторінка може відобразити повідомлення. Початкові картки з’являються після завершення роботи. Для перевірки крайових випадків передавай тривалість явно.
