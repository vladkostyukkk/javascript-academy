## Частка виконаного

FocusBoard має показувати прогрес списку. Оператори +, -, * і / додають, віднімають, множать та ділять числа. % дає остачу, а не відсоток.

```js
const done = 3;
const count = 6;
const percent = done / count * 100; // 50
```

Множення й ділення мають однаковий пріоритет і виконуються зліва направо. Дужки дозволяють явно згрупувати обчислення. 1 / 4 * 100 дає 25, а 1 / (4 * 100) — інше число.

## Порожній список

0 / 0 дає NaN — спеціальне числове значення невдалого обчислення; 1 / 0 дає Infinity. Для лічильників задач домовляємося: порожній список має 0% виконання.

Math.max(a, b) — готова команда JavaScript, яка повертає більше з двох чисел. Назва перед дужками викликає команду, аргументи передаються через кому. Власні функції вивчатимемо пізніше.

```js
const done = 0;
const count = 0;
const percent = done / Math.max(count, 1) * 100; // 0
```

Ця формула призначена для цілих невід’ємних лічильників, де done не перевищує count. Вона не перевіряє довільний ввід і не виправляє від’ємні значення.

## Перевір себе

Для 2 із 4 результат 50; для 4 із 4 — 100; для 0 із 0 — 0 з нашим захищеним знаменником. Не додавай знак % до числового результату: це буде рядок.
