## Коротка функція зі стрілкою

Функцію, що одразу обчислює результат, можна записати як стрілкову. Її можна присвоїти змінній `const` і викликати за іменем цієї змінної.

```js
const addBuffer = (minutes) => minutes + 5;
const timeWithBuffer = addBuffer(20);
console.log(timeWithBuffer); // 25
```

Ліворуч від `=>` записані параметри, праворуч — вираз. У такій формі результат виразу повертається без окремої команди `return`.

## Тіло з фігурними дужками

Для кількох команд використовуй блок. Усередині блоку результат треба явно повернути.

```js
const twice = (minutes) => {
  const result = minutes * 2;
  return result;
};

console.log(twice(15)); // 30
```

Якщо видалити `return result`, виклик із блоком поверне `undefined`. Стрілкову функцію, присвоєну `const`, можна викликати після цього присвоєння.

## Виклик з іншої функції

Результат виклику можна підставити в шаблонний рядок. Якщо різні підписи потребують однакового формату часу, спільна функція забезпечує той самий суфікс для кожного числа. Перевір, що короткий запис після стрілки повертає весь потрібний рядок.
