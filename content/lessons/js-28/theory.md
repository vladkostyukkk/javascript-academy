## Вибрати всі збіги через filter

`filter` приймає функцію з умовою для кожного елемента. Елемент потрапляє до нового масиву, якщо результат умови істинний. Результат зберігає порядок збігів. Якщо збігів немає, метод повертає порожній масив.

```js
const scores = [3, 8, 10, 5];
const highScores = scores.filter((score) => score >= 8);

console.log(highScores); // [8, 10]
console.log(scores); // [3, 8, 10, 5]
```

`map` створює значення для кожного елемента. У `filter` повернене з callback значення лише визначає, чи відібрати елемент. Сам результат містить відібрані числа або об’єкти з вхідного списку.

## Знайти перший збіг через find

`find` також приймає функцію з умовою. Він повертає перший елемент, для якого результат умови істинний, і зупиняється. Коли такого елемента немає, результат дорівнює `undefined`.

```js
const books = [
  { id: 1, title: "Мандрівка" },
  { id: 2, title: "Сад" },
];

const book = books.find((item) => item.id === 2);
const missingBook = books.find((item) => item.id === "2");

console.log(book.title); // Сад
console.log(missingBook); // undefined
```

Запис `===` вимагає збігу значення й типу. Рядок `"2"` не збігається з числовим ID `2`. Перед читанням властивості знайденого об’єкта можна перевірити, чи результат відрізняється від `undefined`.

## Підбери форму результату

Для всіх збігів використай `filter`, для одного збігу — `find`. Обидва методи залишають вхідний список без змін, якщо callback лише читає елементи. Якщо треба змінити знайдену задачу незалежно від вихідної, можна створити її копію через `updateTask` з попереднього уроку.
