## Текст картки

Раніше ми об’єднували рядки через +. Шаблонний рядок дозволяє вставляти значення прямо в текст: він оточений зворотними лапками `, а вставка має вигляд ${вираз}.

```js
const title = "Прочитати розділ";
const duration = 15;
const label = `${title}: ${duration} хв`;
```

Результат — рядок «Прочитати розділ: 15 хв». Число всередині вставки стає текстовим представленням; сама duration залишається числом. Можна вставити вираз, наприклад ${duration + 5}.

## Пробіли та лапки

Звичайні подвійні лапки не виконують вставки: "${title}" залишиться буквальним текстом. Пробіли, роздільники та переноси рядків усередині шаблону зберігаються. Для компактної картки використовуй один рядок.

## Нуль і порожній текст

Вставка числа 0 показує символ 0; вставка порожнього рядка нічого не додає, але сусідні пробіли залишаються. Шаблон не перевіряє коректність даних і не малює HTML.

## Перевір себе

Яким буде `${2 + 3} хв`? Рядком «5 хв». Чому "${2 + 3} хв" дає інший результат? Звичайні лапки не обчислюють вставки.
