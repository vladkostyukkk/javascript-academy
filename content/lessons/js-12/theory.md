## Три результати одного рішення

Після `if` можна додати `else if` з іншою умовою. JavaScript перевіряє умови згори вниз. Щойно умова дає `true`, виконується її блок, а решту ланцюжка JavaScript пропускає. Якщо всі умови дали `false`, виконується останній блок `else`.

Розглянь чергу нагадувань. Якщо термін уже минув, покажемо «Прострочено». Для решти нагадувань перевіримо, чи термін припадає на сьогодні.

```js
const daysLeft = 0;
let reminder = "";

if (daysLeft < 0) {
  reminder = "Прострочено";
} else if (daysLeft === 0) {
  reminder = "На сьогодні";
} else {
  reminder = "Попереду";
}

console.log(reminder);
```

Для `0` перша умова хибна, друга істинна. Вихід — «На сьогодні». Підстав `-1` і `1`, щоб побачити решту результатів.

## Порядок умов

Умови іноді можуть бути істинними одночасно. Уяви, що для задачі збереглися дві ознаки: її почали й уже завершили. Якщо спочатку перевірити, чи її почали, ланцюжок вибере статус «У роботі». Щоб завершена задача отримала статус «Готово», перевір завершення першим.

Два окремі `if` можуть виконати обидва блоки. Якщо вони присвоюють значення одній змінній, другий блок може перезаписати результат першого. Ланцюжок `if / else if / else` записує результат один раз.

Перед практикою подумай, у яку гілку потрапить задача, яку ще не почали й не завершили.
