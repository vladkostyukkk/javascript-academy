## Дві гілки одного рішення

У FocusBoard є числовий пріоритет задачі. Щоб показати його словами, потрібно вибрати одну з двох позначок. Порівняння повертає `true` або `false`, а `if / else` визначає, яку дію виконати.

Розглянь подібне рішення для тривалості. FocusBoard має попередити про перевищення ліміту, коли запланований час більший за нього.

```js
const plannedMinutes = 20;
const limit = 20;
let timeLabel = "";

if (plannedMinutes > limit) {
  timeLabel = "Понад ліміт";
} else {
  timeLabel = "У межах ліміту";
}

console.log(timeLabel);
```

Умова в круглих дужках тут дає `false`, бо 20 не більше за 20. Виконується лише блок `else`, тож консоль покаже «У межах ліміту». Зміни `plannedMinutes` на 21. Тепер умова дає `true` і виконується лише блок `if`.

## Як зберегти результат

Оголоси змінну з `let` перед `if`, щоб скористатися нею після обох гілок. Усередині кожної гілки присвой значення тій самій змінній. Якщо в гілці знову написати `let timeLabel`, виникне окрема змінна, а зовнішня `timeLabel` залишиться порожньою.

Якщо пропустити `else`, хибна умова залишить початкове значення. Тут обидва результати потрібні, тож кожна гілка має записати свій текст.

## Що відбувається на межі

Спочатку скажи правило словами. «Більше за 20» відповідає `> 20`, а «20 або більше» — `>= 20`. Для задачі на 20 хвилин ці умови дають різні результати.

Перед практикою визнач, яким буде `timeLabel`, якщо `plannedMinutes` дорівнює 19. Потім подумай, що зміниться для рівно 20 хвилин, якщо замінити `>` на `>=`.
