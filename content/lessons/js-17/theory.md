## Кілька параметрів і типовий аргумент

Окремій назві задачі можна дати тривалість за замовчуванням. В оголошенні функції параметри відділяються комою, а запис `minutes = 10` біля параметра задає початкове значення, яке JavaScript підставить за потреби.

```js
function addBreak(workMinutes, breakMinutes = 10) {
  return workMinutes + breakMinutes;
}

console.log(addBreak(20)); // 30
console.log(addBreak(20, 5)); // 25
console.log(addBreak(20, 0)); // 20
```

Порядок аргументів відповідає порядку параметрів. У першому виклику другого аргументу немає, тому `breakMinutes` отримує `10`. У другому й третьому викликах значення передано явно.

## Пропущене значення і нуль

Пропущений аргумент має значення `undefined`. Для параметра з типовим значенням JavaScript у цьому випадку підставляє значення з оголошення. Явний `0` залишається нулем, тому його можна використовувати для задачі, яка не потребує часу.

Логічний оператор `||` дає іншу поведінку. Вираз `breakMinutes || 10` для нуля дає `10`. Щоб зберегти нуль і заповнити лише пропущений аргумент, задай типове значення у списку параметрів.

## Форматування результату

Результатом функції може бути і рядок. Передай назву й тривалість через параметри та підстав обидва значення у шаблонний рядок. Перевір, який текст формується для однієї назви з явною тривалістю та для іншої без неї.
