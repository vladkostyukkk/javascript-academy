## Одна функція для повторюваного правила

FocusBoard уже обчислює текстовий пріоритет для двох задач. Якщо однакове правило записано двічі, редагувати доведеться обидва блоки. Функція дає правилу ім’я, щоб застосовувати його до різних даних.

## Оголошення і виклик

Ключове слово `function` починає оголошення. Далі йдуть ім’я, параметр у круглих дужках і тіло у фігурних дужках.

```js
function addBuffer(minutes) {
  const result = minutes + 5;
  return result;
}

const studyTime = addBuffer(25);
const readingTime = addBuffer(10);
console.log(studyTime); // 30
console.log(readingTime); // 15
```

`minutes` у першому рядку — параметр. У виклику `addBuffer(25)` число `25` — аргумент, який отримає цей параметр. Кожен виклик обчислює результат зі своїм аргументом.

Команда `return result` передає значення туди, де функцію викликали. Коли виклик стоїть праворуч від `=`, змінна ліворуч отримує повернене значення.

## Функція з умовою

У тілі функції можна використати знайомі `if` і `else`. Визнач результат у потрібній гілці, а потім поверни його. Так усі виклики застосують однакову умову, зокрема й на межі.

Поширена помилка — читати змінну конкретної задачі в тілі функції. Тоді переданий аргумент не впливає на результат. Перевір себе двома різними викликами й порівняй значення, збережені у змінних.
