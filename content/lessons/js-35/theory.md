## Делегування подій

Клік по кнопці спливає до контейнера карток. Тому можна встановити один обробник на контейнер, навіть якщо картки згодом перемальовуються.

```js
container.addEventListener("click", (event) => {
  const button = event.target.closest("button");
  if (!button) return;
  console.log(button.textContent);
});
```

`event.target` може бути вкладеним елементом усередині кнопки. Метод `closest()` перевіряє сам елемент і його предків. Якщо відповідника немає, він повертає `null`. Атрибут `data-task-id` доступний як `dataset.taskId`. Значення з `dataset` є рядком, тому перетвори його на число перед пошуком у масиві.
