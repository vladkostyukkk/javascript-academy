## Звідки функція бачить змінні

Усередині функції можна оголосити власні змінні. Код зовні не може звертатися до їхніх імен напряму. Вкладена функція бачить змінні тієї функції, у якій її оголосили.

## Лічильник, який зберігає стан

Зовнішня функція може повернути внутрішню. Внутрішня функція збереже доступ до своєї зовнішньої змінної навіть після завершення виклику. Такий зв’язок функції з її оточенням називають **замиканням**.

```js
function createStepCounter(start) {
  let value = start;

  return () => {
    value = value + 2;
    return value;
  };
}

const nextStep = createStepCounter(10);
console.log(nextStep()); // 12
console.log(nextStep()); // 14
```

`createStepCounter(10)` створює лічильник і повертає функцію. `nextStep()` викликає цю функцію, змінює `value` й повертає нове число.

## Окремі екземпляри

Новий виклик `createStepCounter(10)` створює нову змінну `value`. Якщо викликати отримані функції по черзі, кожна продовжить власний рахунок. Змінна за межами зовнішньої функції була б спільною, а змінна всередині тіла поверненої функції створювалася б заново при кожному кроці.

Перевір себе. Після двох викликів `nextStep()` новий лічильник із початковим числом 10 поверне 12, а наступний виклик першого лічильника поверне 16.
