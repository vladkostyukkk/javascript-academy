## Пошук

Подія `input` виникає під час введення або очищення поля. Для пошуку за частиною рядка підходить `includes()`. Щоб регістр і зовнішні пробіли запиту не впливали на результат, нормалізуй запит і назву.

```js
const query = field.value.trim().toLowerCase();
const matches = tasks.filter((task) =>
  task.title.toLowerCase().includes(query),
);
```

Порожній запит збігається з кожною назвою. Пошук застосовуй до задач, які вже пройшли фільтр статусу, інакше приховані задачі несподівано повернуться.
