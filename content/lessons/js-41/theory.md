## ES-модулі

Після js-40 один файл містить і правила для даних, і весь інтерфейс. ES-модуль має власну область видимості. Це дає змогу перенести функцію в окремий файл і явно визначити, що з нього доступне зовні.

### Два файли, один застосунок

У файлі `src/domain/labels.js` можна оголосити іменований експорт.

```js
export function getStatusLabel(status) {
  return "Статус: " + status;
}
```

У `src/app.js` звертаємося до нього за відносним шляхом.

```js
import { getStatusLabel } from "./domain/labels.js";

console.log(getStatusLabel("У роботі"));
```

Шлях починається від файла з імпортом. Тут `./domain/labels.js` означає «папка domain поруч з app.js». Фігурні дужки перелічують імена, які модуль експортує. Якщо файл або ім’я не знайдено, застосунок не почне виконання.

Винось у предметний модуль перетворення й перевірки, яким достатньо аргументів. Обробники подій і створення карток лишаються біля інтерфейсу. Після перенесення функцій їхні виклики працюють так само. У перегляді Академії модулі завантажуються з файлів редактора. Для звичайної HTML-сторінки точку входу підключають як `<script type="module" src="src/app.js"></script>`.
