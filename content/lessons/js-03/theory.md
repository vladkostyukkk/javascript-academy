## Текст у FocusBoard

Назва задачі вже зберігається в taskTitle. Додамо категорію та підпис, який пізніше використає картка FocusBoard. Рядок — це текстове значення: літери, цифри, пробіли та розділові знаки між лапками.

## Лапки та імена

Одинарні й подвійні лапки однаково утворюють рядок. Відкривальна й закривальна лапки мають збігатися. Ім’я без лапок читає значення змінної; ім’я в лапках є звичайним текстом.

~~~js
const name = "Прочитати розділ";
console.log(name);
console.log("name");
~~~

Перша команда показує Прочитати розділ, друга — name. Порожній рядок записують як дві лапки без символів між ними: "". Рядок " " не порожній: він містить пробіл.

## Об’єднання оператором +

Коли по обидва боки + стоять рядки, JavaScript з’єднує їх у новий рядок зліва направо. Початкові значення не змінюються. Пробіли самі не додаються.

~~~js
const name = "Прочитати розділ";
const section = "Книги";
const label = name + " / " + section;
console.log(label);
~~~

Результат: Прочитати розділ / Книги. Пробіли біля / входять до середнього рядка. Якщо прибрати їх, частини злипнуться. Порожній рядок при об’єднанні не додає символів.

## Типові помилки

- "name" + section додає буквальне слово name, а не назву.
- name + section не додає роздільника або пробілу.
- Зайвий пробіл наприкінці є частиною рядка: точні значення відрізнятимуться.
- Дефіс - і тире — є різними символами. Використовуй заданий роздільник; його можна скопіювати з умови.

Не змінюй попередні змінні заради нового підпису. Оголоси окрему змінну, яка читає їхні значення. Для цієї вправи достатньо +: інші способи складання тексту з’являться пізніше.
