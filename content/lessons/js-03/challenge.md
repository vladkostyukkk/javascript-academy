## Підпис задачі FocusBoard

Продовжуй попередній проєкт у src/app.js. Збережи appName, taskTitle, priority, minutes та одне наявне console.log(appName). HTML і CSS залишаються доступними лише для читання.

1. Оголоси const category зі значенням "Навчання".
2. Оголоси const taskLabel. Об’єднай taskTitle, рядок-роздільник " — " і category оператором +.
3. Кінцевий підпис має точно дорівнювати "Вивчити JavaScript — Навчання": один пробіл з кожного боку тире, без пробілу наприкінці.
4. Натисни «Перевірити». Має пройти сім перевірок, включно з результатами попередніх уроків.

Перевірки оцінюють кінцеві значення та консоль. Вони не визначають, яким синтаксисом складено підпис: самостійно звір, що використав змінні й оператор +, а не готовий текст у лапках. Для експерименту можна тимчасово вивести taskLabel у консоль, але перед Check прибери додатковий log: очікується лише попереднє виведення FocusBoard.

Після успішного Check явно заверши урок, щоб зберегти checkpoint. Додані category і taskLabel стануть основою подальшої роботи.
