## async / await

Функція з `async` завжди повертає Promise. `await` чекає на результат лише всередині цієї функції. Інший код сторінки може працювати далі.

```js
async function loadLabels(labels) {
  await delay();
  return [...labels];
}
```

Якщо після запуску завантаження учень вже змінив дошку, результат із початковими даними не має перезаписати новий стан. Перевір поточне посилання на стан перед застосуванням результату.
