## Порівняння часу

Оператори > і < означають більше та менше, >= і <= допускають рівність. Результат порівняння — булеве true або false.

```js
const duration = 30;
const limit = 30;
const tooLong = duration > limit; // false
const fits = duration <= limit; // true
```

## Межа та типи

Рівність не є перевищенням. Нуль не перевищує додатний ліміт. Для строгої рівності використовуй ===, для нерівності !==. Число 30 і рядок "30" не є строго рівними. = присвоює значення, а === порівнює. Тут тривалості є числами; зовнішній ввід розглянемо пізніше.

## Перевір себе

Що повернуть 10 > 10 та 10 <= 10? Відповідно false і true: другий оператор допускає рівність.
