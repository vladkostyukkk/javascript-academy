## Вийти з функції, щойно відомий результат

`return` повертає значення виклику й завершує поточний виклик функції. Тому для невдалих умов можна повертати помилку одразу. Далі в тілі лишається шлях для даних, які вже пройшли ці перевірки.

```js
function validateEstimate(minutes) {
  if (minutes < 0) {
    return "Тривалість має бути невід’ємною.";
  }

  return null;
}

console.log(validateEstimate(-5)); // Тривалість має бути невід’ємною.
console.log(validateEstimate(0)); // null
```

Тут `null` означає, що помилки немає. Це окреме значення без лапок. `"null"` — рядок із чотирьох літер. Якщо виконання дійде до кінця функції без `return`, вона поверне `undefined`.

## Спочатку тип, потім вміст

Вираз `typeof value === "string"` перевіряє, чи значення є рядком. У перевірці назви спочатку оброби не-рядкові значення. Для рядка вже можна безпечно викликати `.trim()`.

```js
console.log("  Читати  ".trim()); // Читати
console.log("   ".trim() === ""); // true
```

`.trim()` повертає рядок без пробільних символів на початку й у кінці. Тому порівняння з порожнім рядком виявить і порожню назву, і назву лише з пробілів. Початковий рядок від цього виклику не змінюється.

Перевір порядок дій подумки. Якщо передано число, виконання має завершитися на перевірці типу. Якщо передано рядок «  Читати  », після обрізання є текст, тож функція доходить до `return null`.
