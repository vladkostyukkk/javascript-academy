## Вставка та видалення через splice

Задачі в списку змінюються. Метод `splice` змінює сам масив: може видалити елементи й вставити нові на вказане місце. Перший аргумент задає початковий індекс, другий — скільки елементів видалити. Додаткові аргументи задають значення для вставки.

```js
const stops = ["Київ", "Львів"];

stops.splice(1, 0, "Тернопіль");
console.log(stops); // ["Київ", "Тернопіль", "Львів"]

stops.splice(0, 1);
console.log(stops); // ["Тернопіль", "Львів"]
```

Після вставки елементи від вказаної позиції зсуваються вправо. Після видалення наступні елементи зсуваються вліво. Перед кожною дією звіряй індекс із поточним списком. `const` зберігає за іменем той самий масив, а `splice` змінює його вміст.

## Межі залежать від дії

- Для вставки підходять цілі індекси від `0` до `length` включно. Індекс `length` ставить новий елемент у кінець.
- Для видалення підходять цілі індекси від `0` до `length - 1`. У порожньому списку видаляти нічого, а вставити перший елемент можна за індексом `0`.

`Number.isInteger(index)` повертає `true` для цілого числа, наприклад `2`. Для `1.5` і рядка `"2"` він повертає `false`. Перед `splice` також перевір межі. Наприклад, `splice` розуміє від’ємний індекс як позицію з кінця списку. У FocusBoard відхиляємо такі індекси, щоб випадково не змінити іншу задачу.

## Ранній вихід

Функція може повідомити, чи виконалася зміна: повернути `false` при некоректній позиції та `true` після успішного виклику `splice`.

```js
function insertBreak(breaks, index) {
  if (!Number.isInteger(index) || index < 0 || index > breaks.length) {
    return false;
  }

  breaks.splice(index, 0, "Перерва");
  return true;
}
```

Перевір себе. Яким буде `breaks` після двох викликів `insertBreak(breaks, 0)` і `insertBreak(breaks, 3)`, якщо спочатку `breaks = []`? Перший виклик поставить «Перерва» за індексом `0`. Другий поверне `false`, бо довжина списку тоді дорівнює `1`.
