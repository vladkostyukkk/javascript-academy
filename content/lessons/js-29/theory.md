## Порівняй два елементи

`sort` упорядковує масив. Без функції порівняння він порівнює елементи як рядки. Наприклад, `[2, 10, 1].sort()` дає `[1, 10, 2]`. Для числового пріоритету передай функцію, яка приймає два елементи `first` і `second`.

- Від’ємне число ставить `first` перед `second`.
- Додатне число ставить `second` перед `first`.
- Нуль залишає початковий порядок цих елементів. Це властивість стабільного сортування.

Для порядку від більшого числа до меншого підійде різниця `second - first`. Якщо `first` дорівнює 10, а `second` дорівнює 2, різниця від’ємна й 10 буде попереду. Для задач так само можна відняти одне значення `priority` від іншого.

## Сортуй копію

`sort` змінює масив, на якому його викликають, і повертає той самий масив. Щоб зберегти початковий порядок, створи копію через spread усередині квадратних дужок.

```js
const priorities = [2, 10, 1];
const ordered = [...priorities];

ordered.sort((first, second) => second - first);

console.log(ordered); // [10, 2, 1]
console.log(priorities); // [2, 10, 1]
```

Масив `ordered` має власний порядок. Якщо елементи є об’єктами, поверхнева копія містить посилання на ті самі об’єкти. Під час сортування читай їхні поля й змінюй тільки порядок елементів у копії.
