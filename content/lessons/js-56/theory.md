## Drag and drop

Під час `dragstart` можна передати ID картки через `dataTransfer.setData`. На потрібній колонці `dragover` має викликати `preventDefault`, щоб дозволити `drop`. Далі знайди цільову колонку та онови статус задачі за ID.

Кнопки переміщення потрібні для клавіатури й пристроїв без перетягування. Обидва способи мають викликати одну функцію оновлення даних.
