## Один об’єкт для однієї задачі

Масив назв допомагає знайти назву за індексом. Для картки FocusBoard ще потрібні ID, статус, пріоритет і хвилини. Об’єкт збирає пов’язані значення під іменованими властивостями.

## Літерал об’єкта

Літерал об’єкта записують у фігурних дужках. Ліворуч від двокрапки ставлять ім’я властивості, праворуч — її значення. Властивості відокремлюють комами.

```js
const name = "Полити квіти";

const reminder = {
  title: name,
  minutes: 5,
  completed: false,
};

console.log(reminder.title); // Полити квіти
console.log(reminder.minutes); // 5
```

У `title: name` ім’я властивості — `title`, а значення береться зі змінної `name`. Для читання достатньо вказати ім’я об’єкта й властивість через крапку, наприклад `reminder.title`.

## Масив об’єктів

Масив може зберігати цілі об’єкти. У виразі `reminders[1].title` спочатку читаємо другий елемент масиву, потім його властивість `title`.

```js
const reminders = [
  { id: 1, title: "Полити квіти", minutes: 5 },
  { id: 2, title: "Полити квіти", minutes: 10 },
];

console.log(reminders[1].title); // Полити квіти
console.log(reminders[1].minutes); // 10
```

Назви можуть збігатися. У FocusBoard власний числовий `id` дає змогу розрізняти задачі. Для третьої картки скористайся тим самим генератором ID, який уже видав перші два ідентифікатори.

## Типи значень

Число `5` і рядок `"5"` мають різні типи. Зберігай хвилини, пріоритет та ID як числа. Для назви й статусу використовуй рядки. Написання статусу має значення, бо подальші перетворення порівнюватимуть ці рядки.

Спробуй передбачити результат `reminders[0].id`. Яке значення покаже `reminders[1].id`, хоча назви збігаються?
