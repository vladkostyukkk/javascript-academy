## Деструктуризація об’єкта

Деструктуризація дає змогу створити змінні зі значень кількох властивостей. У фігурних дужках ліворуч від `=` перелічують їхні імена, а праворуч ставлять об’єкт.

```js
const reminder = { title: "Полити квіти", minutes: 5 };
const { title, minutes } = reminder;

console.log(title); // Полити квіти
console.log(minutes); // 5
```

Імена беруться з властивостей. У прикладі `title` отримує значення `reminder.title`, незалежно від того, яким за порядком записано поле.

## Копія через spread

Запис `{ ...reminder }` створює новий об’єкт і переносить у нього власні перелічувані властивості `reminder`. Для властивостей зі звичайного літерала цього достатньо. Коли ім’я властивості повторюється, останній запис визначає результат.

```js
const reminder = { title: "Полити квіти", minutes: 5 };
const updatedReminder = { ...reminder, minutes: 0 };

console.log(reminder.minutes); // 5
console.log(updatedReminder.minutes); // 0
console.log(updatedReminder === reminder); // false
```

Якщо записати `{ minutes: 0, ...reminder }`, пізніше значення `minutes` із джерела перезапише 0.

## Значення та посилання

У задачі FocusBoard п’ять полів із рядками та числами. Поверхневої копії через spread достатньо, щоб змінювати ці поля в копії незалежно від оригіналу. Якщо у властивості зберігається інший об’єкт, spread переносить посилання на нього, тому вкладений об’єкт лишається спільним.

Оновлена копія має окреме посилання і тоді, коли нове значення збігається зі старим. Який результат дасть `{ ...reminder } === reminder`? Що відбудеться з `reminder.minutes`, якщо змінити `updatedReminder.minutes`?
