## Від тексту до числа

Текстове поле зазвичай дає рядок. У цьому уроці моделюємо його змінною, без DOM. Number(value) — готова команда, що перетворює значення на число.

```js
const input = "45";
const duration = Number(input);
const extended = duration + 5; // 50
```

Без перетворення input + 5 дало б рядок "455". Number(" 45 ") також дає 45, а Number("45 хв") — NaN: одиниці вимірювання не є частиною числа.

## Невдале перетворення

```js
const parsed = Number("невідомо");
const invalid = Number.isNaN(parsed); // true
```

Number.isNaN перевіряє саме числове NaN. Number.isNaN("невідомо") повертає false, бо рядок ще не перетворено. NaN === NaN теж false, тому для цієї перевірки використовуй готову команду.

## Порожнє поле

Number("") і Number("   ") дають 0. Це особливість перетворення, а не доказ, що користувач увів правильну тривалість. Number("-5") дає -5, Number("Infinity") — Infinity; перевірка NaN не є повною перевіркою форми. Відхилення порожнього, від’ємного та нескінченного вводу додамо з умовами й логічними операторами.

## Перевір себе

Number("12") + 3 дає 15. Number.isNaN(Number("12 хв")) дає true. Стару minutes не змінюємо: новий ввід поки окремий приклад.
