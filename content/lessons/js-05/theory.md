## Запитання з двома відповідями

У задачі FocusBoard є назва й тривалість. Тепер потрібні відповіді на запитання «Завершено?» та «Важливо?». Для кожного з них достатньо двох станів. Булевий тип має лише два значення: true (так, істина) та false (ні, хиба).

~~~js
const isPinned = true;
const isArchived = false;
~~~

Ці змінні називають прапорцями. Назва пояснює запитання, значення — відповідь. Прапорець false є повноцінним значенням, а не відсутністю даних або помилкою.

## Без лапок і з маленької літери

true і false записують без лапок. "false" є текстом, а не булевим значенням. Числа 0 та 1 також не є булевими значеннями, навіть якщо в інших системах ними іноді кодують «ні» та «так». True з великої літери не є ключовим словом: JavaScript сприйме його як ім’я змінної.

~~~js
const isPinned = true;
const label = "true";
const count = 1;
~~~

Тут три різні типи даних. Точна перевірка може розрізнити їх навіть тоді, коли їхній вигляд у консолі схожий.

## Прапорець і текстовий статус

Збережемо булеві дані окремо, а для читання складемо рядок знайомим оператором +. Якщо зліва є рядок, булеве значення праворуч стає текстом true або false у результаті об’єднання. Сам прапорець від цього не змінює тип.

~~~js
const isPinned = true;
const isArchived = false;
const summary = "Закріплено: " + isPinned + "; в архіві: " + isArchived;
console.log(summary);
~~~

Результат: Закріплено: true; в архіві: false. Це просте текстове представлення даних. Людські назви станів на кшталт «Готово» або «У роботі» обиратимемо після вивчення умов. Не потрібно вгадувати новий синтаксис зараз.

## Збережене значення не змінюється саме

Для початкових незмінних прапорців підходить const. Якщо пізніше потрібно переприсвоювати стан, можна використати знайомий let. Звичайний обчислений рядок не оновлюється автоматично після зміни прапорця: код формування рядка має виконатися знову. Реакцію на натискання в інтерфейсі додамо на етапі DOM.

## Перевір себе

Чим false відрізняється від "false"? Чому 0 не підходить, коли потрібен саме булевий прапорець? Який текст утворить "Архів: " + false? У практиці опиши незавершену важливу задачу, не змінюючи її назви, категорії та тривалості.
