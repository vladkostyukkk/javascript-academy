## Початковий стан задачі

Продовжуй src/app.js після коду js-04. Збережи всі попередні змінні та одне console.log(appName). HTML/CSS не змінюй.

1. Оголоси const completed зі значенням false: задачу ще не завершено.
2. Оголоси const isImportant зі значенням true: задача важлива.
3. Оголоси const taskStatus. За допомогою + об’єднай "Завершено: ", completed, "; важливо: " та isImportant саме в цьому порядку.
4. Результат має точно дорівнювати "Завершено: false; важливо: true". Прапорці мають залишитися булевими, а не рядками або числами.
5. Натисни «Перевірити»: очікуються дванадцять успішних перевірок.

Check перевіряє значення та тип прапорців, але не доводить спосіб побудови рядка. Самостійно звір, що taskStatus читає completed та isImportant, а не містить готовий текст. Умови й тернарний оператор тут не потрібні. Після тимчасових експериментів у консолі залиш лише попереднє виведення FocusBoard.

Після успішного Check явно заверши урок. Прапорці та статус збережуться в новому checkpoint для подальшого розвитку проєкту.
