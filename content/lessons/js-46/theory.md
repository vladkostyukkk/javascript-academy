## Відновлення даних

`JSON.parse` може повернути число, об’єкт або масив і кидає помилку на пошкодженому рядку. Відновлення потребує обох перевірок: синтаксису JSON і форми даних.

```js
const restored = restoreTasks(raw);
const initialTasks = restored ?? sampleTasks;
```

Порожній масив означає, що користувач видалив усі задачі. Він має лишитися порожнім. Після завантаження обчисли наступний ID від найбільшого з відновлених.
