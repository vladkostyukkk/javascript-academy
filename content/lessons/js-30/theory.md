## Збери підсумок через reduce

`reduce` проходить елементи масиву й накопичує спільний результат. Він приймає функцію та початкове значення. Перший параметр функції — **акумулятор**, тобто підсумок на цей момент. Другий — поточний елемент. Повернене з callback значення стає акумулятором для наступного кроку.

```js
const distances = [4, 0, 6];
const total = distances.reduce((sum, distance) => sum + distance, 0);

console.log(total); // 10
```

1. Початкове значення — `0`. Перший елемент `4` дає `0 + 4 = 4`.
2. Для другого елемента callback отримує `4` і `0` та повертає `4`.
3. Для третього елемента callback отримує `4` і `6` та повертає `10`.

Для порожнього масиву `reduce` повертає початкове значення без виклику callback. Якщо пропустити початкове значення, перший елемент стане акумулятором, а порожній масив спричинить помилку.

## Накопичуй кілька чисел

Акумулятором може бути об’єкт. Створи його в тому самому виклику `reduce`, щоб кожне нове обчислення починалося з нулів. У callback оновлюй поля й повертай акумулятор.

```js
const distances = [4, 0, 6];
const summary = distances.reduce(
  (stats, distance) => {
    stats.count = stats.count + 1;
    stats.distance = stats.distance + distance;
    return stats;
  },
  { count: 0, distance: 0 },
);

console.log(summary); // { count: 3, distance: 10 }
```

Тут змінюється лише новий об’єкт підсумку. У FocusBoard так можна за один прохід порахувати всі задачі, окремо завершені та суму хвилин.
