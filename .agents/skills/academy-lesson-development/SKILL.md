# Урок як внесок у FocusBoard

## Контекст за потреби
Усі шляхи коду нижче — від кореня репозиторію.
- Для авторингу прочитай [контракт уроку](../../../docs/LESSON_CONTRACT.md), потрібний запис маніфесту й відповідний розділ [curriculum](../../../docs/CURRICULUM.md). Поточну фазу перевір у STATE, коли вибираєш наступний урок.
- Для зміни форми пакета переглянь `lib/lessons/schema.ts`, `content-validation.ts`, `content-files.ts`; для доступності — `registry.ts`. Не читай усі існуючі уроки.
- Для обсягу перевірок використовуй [QUALITY](../../../docs/QUALITY.md). Чинне обмеження користувача на продуктові тести поширюється і на авторські sandbox-запуски.

## Робота
1. Знайди пакет у `content/lessons/index.json`; не створюй повторно готовий урок. Визнач навчений раніше синтаксис, один головний концепт і конкретну зміну FocusBoard. Новий урок спирається на попередній cumulative checkpoint, а не незалежну вправу.
2. Використовуй наявну схему й формат пакета: meta, theory, quiz, challenge, editablePaths, starter, checks/negative cases, 3 hints, solution, checkpoint hashes. Reference/checks не додавай до editable fileMap; не розмножуй checker logic по компонентах.
3. Пиши українські пояснення та feedback. Передбач щонайменше 2 edge cases; starter має падати через навмисну прогалину, reference — виконувати очікувану поведінку. Самого пошуку рядків у коді недостатньо.
4. Не форматуйте навчальні JS/HTML/CSS масово. Збережи path allowlist, read-only основу й ліміти чинної схеми. Для зміни вже опублікованої основи/version потрібне рішення про сумісність, без перезапису живих чернеток.
5. Статична валідація — `npm run validate:content` (також входить у prebuild). Поведінка — адресні reference/negative fixtures у наявному sandbox harness; див. `tests/e2e/reference.author.spec.ts`. Він зараз орієнтований на js-01: при новому пакеті потрібне відповідне покриття, його не можна припускати автоматично. Learner JS ніколи не запускай у Node/Next для перевірки.

## Готовність
Матеріали узгоджені з маніфестом і попереднім checkpoint, feedback змістовний, hashes коректні; reference/negative cases та залежні regressions перевірені в дозволеному обсязі. Статична валідація не доводить поведінку. Якщо виконання тестів відкладене, познач пакет неперевіреним і не оголошуй gate пройденим. Наявність пакета не означає unlock наступного уроку. Онови STATE після значущого авторингу; не генеруй десятки уроків заради кількості.
