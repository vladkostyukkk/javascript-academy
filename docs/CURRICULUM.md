# Curriculum — 60 lessons, 6 modules

Every lesson contributes to **FocusBoard**, built with vanilla JavaScript. The authoritative machine-readable identifiers and fields are in `curriculum/manifest.json`.

The curriculum is sequential. 01–30 build domain logic, 31–40 make it visible, 41–50 make it maintainable and persistent, 51–60 add async interaction, UX and export.

## Content invariants

- Do not require objects before lesson 24, functions before lesson 16, DOM APIs before lesson 31, modules before lesson 41, Promise before lesson 51.
- Early exercises may use a prebuilt HTML/CSS shell. Their output must be reused in later app logic; they are not independent toy exercises.
- Complete a manual review of at least one representative lesson from each module before mass-generating the remaining ten.
- A previous reference checkpoint must always remain downloadable or recoverable.
- Allow future content revisions with migration/version awareness, never silent overwrite of learner files.
