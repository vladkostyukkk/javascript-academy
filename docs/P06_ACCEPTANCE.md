# Приймання P06 — перші десять уроків

Дата: 2026-11-18. Обсяг: локальний навчальний продукт; це не security/release gate.

## Матеріали та педагогічний перегляд

Вручну переглянуто тексти теорії, завдання, quiz, підказки й еталонну послідовність 01–10. Кожна практика продовжує FocusBoard, зберігає попередні дані та пояснює очікувані значення. HTML/CSS основа незмінна. Приклади не потребують умов, власних функцій чи DOM до їхніх модулів.

| Урок | Концепт / крайові випадки | Checks |
|---|---|---:|
| 01 | console, ім’я; регістр, пробіли, дубль log | 2 |
| 02 | let/const; числовий і рядковий тип | 5 |
| 03 | рядки; порожня категорія, роздільники | 7 |
| 04 | числа; нуль, від’ємне, рядкова сума | 9 |
| 05 | boolean; рядки та числа замість прапорців | 12 |
| 06 | порівняння; рівність для > і <= | 16 |
| 07 | арифметика; нульовий знаменник, масштаб відсотка | 20 |
| 08 | шаблонні рядки; буквальна вставка, нуль у тексті | 22 |
| 09 | Number/isNaN; неперетворений текст, порожній ввід | 26 |
| 10 | інтеграція; знак різниці, напрям порівняння, одиниці | 29 |

Math.max у 07 та Number/Number.isNaN у 09 пояснені як готові команди до використання (ADR-023). Захищена формула відсотка діє для невід’ємних цілих лічильників, де виконаних не більше загальної кількості. Перевірка NaN не оголошена повною валідацією форми. Check оцінює поведінку, але не доводить використання формули замість константи; це явно пояснено в завданнях. Це локальна навчальна перевірка, а не захист від списування.
