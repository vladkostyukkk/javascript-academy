# P01 — звіт перевірки оболонки

Дата: 2026-11-13. Середовище: Windows, Node.js 24.20.0, npm 11.19.0, Microsoft Edge (Playwright channel `msedge`).

## Реалізований обсяг

- Next.js App Router, TypeScript strict, Tailwind 4, адаптовані shadcn/ui Button/Tabs, локальні шрифти.
- Головна, програма курсу, демонстрація уроку, сторінка FocusBoard, loading/error/not-found.
- Карта 6 × 10 із незміненого маніфесту, пошук за темою/ціллю/ID, порожній результат, розгортання модулів і переходи лише до наявних результатів пошуку.
- Демонстрація js-01 з вкладками Теорія/Практика/Перевірка. Уроки js-02…js-60 залишаються заблокованими навіть після прямого переходу чи reload.
- Мобільне меню з `aria-expanded`, Escape та поверненням фокуса; skip link, активний маршрут і клавіатурні вкладки.
- Жодного виконання learner JS, редактора, фіктивних результатів, записів прогресу або експорту.

## Матриця перевірок

| Перевірка | Результат |
|---|---|
| `npm run lint` | Успішно, без помилок і попереджень ESLint |
| `npm run format:check` | Успішно |
| `npm run typecheck` | Успішно: Next typegen + TypeScript |
| `npm test` | 3/3 unit: ID/порядок/залежності, модулі, граничні та невідомі ID |
| `npm run build` | Успішна production-збірка, генерація 66 сторінок |
| `npm run test:e2e` | 19 пройдено, 2 свідомо пропущено: сценарій 320 px запускається лише у mobile-профілі |
| HTTP головної сторінки | 200 на локальному production-сервері |
| Axe WCAG A/AA | 0 порушень на 4 основних сторінках у 3 viewport-профілях |
| Адаптивність | 1440 × 1000, 820 × 1180, Pixel 7; додатково 320 × 740 без горизонтального overflow |
| `npm audit --omit=dev --json` | 0 знайдених runtime-вразливостей |

E2E перевіряють переходи, пошук без урахування регістру/зовнішніх пробілів, порожній пошук, відсутність фальшивих Run/Check/Complete, блокування після reload, невідому адресу, skip link, Arrow/Home/End для вкладок, мобільне меню та Escape. У головному наскрізному сценарії браузерних `pageerror` не було.

Знімки всіх чотирьох сторінок генеруються в `test-results/`; HTML-звіт — `playwright-report/index.html`. Ці локальні артефакти ігноруються Git. Візуально переглянуто головну desktop/mobile, сторінку уроку tablet та карту mobile. Автоматична перевірка axe не означає повної сертифікації доступності; Firefox/Safari й ручний screen-reader аудит не виконувалися.

## Виправлені проблеми та межі

- Початковий lint виявив неекрановані лапки JSX та анонімний export конфігурації PostCSS; виправлено, фінальний lint чистий.
- Спроба ESLint 10 виявила несумісні peer-діапазони плагінів Next.js. Зафіксовано сумісний ESLint 9.39.5; він deprecated. `npm audit` повідомляє 7 moderate зауважень у dev-ланцюжку typescript-eslint/minimatch. Сумісний `npm audit fix` їх не усунув. Це борг інструментів перед релізом; runtime audit чистий. Примусові major-оновлення не застосовувалися.
- У Windows sandbox один запуск завершив усі тести, але затримався при teardown сервера; після адресного завершення підтвердженого власного Next.js процесу отримано exit 0. Фінальний повторний `npm run test:e2e` з дозволом на запуск/прибирання процесів завершився самостійно: 19 passed / 2 skipped, 32.9 s, exit 0. Сервер автоматично зупинився.
- Безпечний runner, ES-модулі у sandbox, адаптер localStorage, навчальна прогресія та міграції ще не перевірені: це наступні фази, не функції P01.

Git ініціалізовано за дорученням користувача; комітів і remote не створювали. Публікації не було.
