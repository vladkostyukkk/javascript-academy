# Приймання P10 — архітектура та збереження

P10 прийнято 2026-11-23. Уроки js-41–js-50 додають до FocusBoard ES-модулі й реекспорти, store, незмінні оновлення, JSON-сховище з відновленням і міграцією, дедлайни, сортування та Undo.

- Production build пройшов для 60 ID, 50 пакетів і 67 сторінок. Пройшли 107 unit-тестів, lint і `git diff --check`.
- Desktop Edge підтвердив еталони та негативні сценарії js-41–js-50, попередні режими runner, незмінність попередніх даних і межу десяти записів історії Undo.
- Наскрізний сценарій js-01–js-50 підтвердив успадкування файлів, відновлення старого масиву задач, міграцію в новий формат при записі, збереження порядку після reload та запасний результат при пошкодженому JSON.
- Завантажений через `/project` checkpoint JSON js-50 повторно пройшов Check в ізольованому runner. ZIP і незалежний запуск фінального проєкту належать до наступної фази.

Дані перегляду зберігаються в межах вкладки й уроку. Тести виконано в desktop Edge. Публічне приймання безпеки runner залишається відкритим. [Адаптер сховища](DECISIONS.md#adr-029--сховище-перегляду-p10) · [Межі runner](P03_RUNNER.md)
