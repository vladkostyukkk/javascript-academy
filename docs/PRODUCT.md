# Product requirements — JavaScript Academy

## Vision
Навчити початківця JavaScript через 60 послідовних уроків і 1 накопичувальний pet-проєкт **FocusBoard**. Теорія → контроль розуміння → практика → автоматична перевірка → збережений результат → наступний урок.

## Target learner
Початківець JS, який уже може знати HTML/CSS, але не повинен знати React. Українськомовна теорія, пояснення простими словами, короткі вправи з прикладами й негативними випадками.

## Information architecture
- `/` — лендінг + останній прогрес.
- `/course/javascript` — дорожня карта 6 модулів × 10 уроків.
- `/learn/javascript/[lessonId]` — теорія / практика / результат, один URL.
- `/project` — огляд і експорт FocusBoard, історія checkpoint-ів.
- `/settings` — персональні навчальні налаштування (пізніше).

## Core lesson UX
1. **Theory**: короткий опис «Навчишся…», пояснення, приклади JavaScript, типові помилки, контрольні питання.
2. **Transition**: користувач завершує мініперевірку і натискає «Перейти до практики». Не потрібно блокувати повернення до теорії.
3. **Practice**: задачі та acceptance criteria, Monaco з вкладками файлів, консоль, тести, DOM preview для відповідних уроків, три послідовні підказки, Reset лише з підтвердженням.
4. **Check**: «Запустити» виконує код, «Перевірити» запускає тести; помилки прив’язані до очікуваної поведінки, не лише до синтаксису.
5. **Complete**: дозволено, коли тести й перевірка цілісності пройдені; зберегти checkpoint та відкрити наступний урок.

## Course progression invariants
- 60 уроків, єдина стабільна нумерація `js-01`..`js-60`.
- Кожний урок має конкретний практичний внесок у FocusBoard.
- Починаючи з уроку 2, workspace базується на checkpoint попереднього уроку (або на офіційному відновлювальному starter checkpoint після явного вибору учня).
- Учнівські зміни не перезаписуються під час оновлення курсу; при конфлікті потрібна міграція або явний вибір.
- Результати роботи зберігаються автоматично; збережена практика переживає перезавантаження сторінки.
- Можна повторити попередній урок у **fork/копії**, не псуючи актуальний робочий проєкт.
- Після уроку 60 застосунок можна експортувати в ZIP та запустити локально через dev server.

## Scope
**MVP:** карта курсу, теорія, редактор, ізольований runner, консоль, preview, тести, підказки, відновлювані чернетки, 60 уроків із checkpoint-ами, експорт кінцевого проєкту.

**Next:** акаунти та синхронізація між пристроями, відстеження статистики, ачивки, AI-тьютор, сертифікат, інші курси.

Якщо auth і база потрібні для першого публічного релізу — додаємо після підтвердження стабільності runner, не заважаючи реалізації локального MVP.

## Accessibility and responsive
- Desktop-first IDE + функціональна мобільна версія (теорія повноцінна; редактор із перемиканням панелей).
- Контраст, keyboard navigation, aria labels, помилки для screen reader, focus management.
- Підтримка світлої / темної теми як другорядна UX-функція.

## Success criteria
Не оцінювати продукт лише за кількістю сторінок. Перевірити, що початківець проходить урок 1 → зберігає код → відкриває урок 2; DOM вправи реально змінюють preview; всі 60 checkpoint-ів запускаються; фінальний експорт FocusBoard працює окремо від платформи.
