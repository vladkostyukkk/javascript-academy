# Аудит релізу P12

## Рішення щодо релізу

Публічний запуск runner відкладено. Наявний opaque iframe ізолює походження документа й обмежує мережеві API через CSP. Відомі межі щодо блокування браузера та вихідної навігації залишаються блокерами. Перевірка цих меж спирається на попередні зафіксовані результати P03 та рев’ю поточного коду. [Межі runner](P03_RUNNER.md#відомі-межі--блокери-публічного-запуску)

На хостингу Run, Check і запуск лабораторії недоступні. Спільний controller відхиляє запуск до створення iframe на адресах поза loopback. Курс і редактор доступні для перегляду та роботи з чернетками; для перевірки коду потрібна локальна копія. Це обмеження доступу до наявного runner. Повноцінний публічний runner потребує іншої моделі ізоляції.

## Результати рев’ю

- Runner у controller приймає сховище перегляду лише для модульного Run із файлом адаптера. CSP, sandbox та перевірка source, origin і ключів запуску збережені. Автоматичне приймання охоплює звичайні навчальні потоки. Діагностичні стенди P03 перевіряються окремо.
- Синтаксичні помилки на етапі підготовки коду отримують український відгук. Невдалий Check не дає підтвердити завершення.
- Сторінка FocusBoard пояснює, де отримати фінальний ZIP. Усі 60 пакетів, контрольні суми й поступове успадкування перевіряються валідатором та браузерними сценаріями.
- Прогрес і чернетки зберігаються в IndexedDB, дані перегляду живуть у сховищі вкладки, експорт створюється в браузері. Незалежний FocusBoard використовує власне сховище за адресою локального сервера.
- Нестиснені файли збірки: runtime 24 477 Б, Monaco editor 4 053 843 Б, TypeScript worker 7 038 273 Б. HTML js-60 становив 63 687 Б до стиснення. Це розміри файлів локальної збірки. Turbopack повідомив про широкий шаблон трасування контенту.

## Локальна перевірка production-збірки

Виконуйте з кореня репозиторію на Node.js 24. `npm run start` слухає loopback. У локальній перевірці достатньо встановленого Edge на Windows або Chromium Playwright на Linux.

```sh
npm ci
npm run lint
npm test
npm run build
npm run typecheck
npm run test:e2e:release
npm run start
```

На Linux перед браузерними тестами встановіть Chromium і системні залежності командою `npx playwright install --with-deps chromium`. Після запуску відкрийте домашню сторінку, карту курсу й історію FocusBoard. Для кількох середовищ зберігайте стабільний origin, оскільки дані браузера прив’язані до адреси.

У локальному smoke шість маршрутів повернули HTTP 200: домашня сторінка, карта курсу, перший і останній уроки, історія FocusBoard та runtime. Запити виконано під час браузерного прогону, тому їхній час слугує діагностикою, без порівняння з релізним бюджетом продуктивності.

GitHub Actions налаштовано для main і pull request з Node.js 24 та Chromium. CI запускає `test:e2e:release`, який залишає спеціалізовані `runner-loop.author.spec.ts` і `runner-security.author.spec.ts` поза звичайним браузерним прогоном. [Checkout](https://github.com/actions/checkout) · [Setup Node.js](https://github.com/actions/setup-node)

## Фактичні прогони 2026-11-23

- `npm run build` перевірив 60 пакетів, SHA-256 і зібрав 67 сторінок. `npm run typecheck`, `npm run lint`, `npm test` (107 тестів) і `git diff --check` пройшли.
- `npm run test:e2e:release -- --workers=4` виконав матрицю desktop/tablet/mobile у Edge. 129 пройшли, 17 впали, 2 вузькі сценарії заплановано пропущено на desktop/tablet. Наскрізний js-01–js-60, незалежний ZIP і перевірки axe для ключових сторінок пройшли в цьому прогоні.
- Виправлено застарілі очікування доступу та статусів у тестах, старт авторського стенда Edge й діагностику помилок синтаксису. `npm run test:e2e:release -- --last-failed --workers=2` повторив усі 17 невдалих сценаріїв, усі пройшли. Ліміти виконання runner не збільшувалися.
- На фінальній збірці повторно пройшли три сценарії axe і viewport для desktop/tablet/mobile та автономний запуск ZIP.
- Хмарний GitHub Actions і зовнішній хостинг залишаються неперевіреними. Публічне приймання заблоковане відкритими питаннями ізоляції.
