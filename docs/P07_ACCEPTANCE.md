# Приймання P07 — умови та функції

Дата — 2026-11-21. Обсяг — локальний навчальний продукт і накопичувальні контрольні точки 01–20.

## Матеріали

Кожний js-11–js-20 має українську теорію, quiz, практику, три підказки, еталон та контрольні суми SHA-256. Кожний starter дослівно успадковує еталон попереднього уроку. HTML і CSS FocusBoard лишаються спільною основою для цього модуля.

| Урок | Практика й приклади меж | Checks | Крайові сценарії |
| --- | --- | ---: | ---: |
| js-11 | Позначка пріоритету для 1 і на порозі 2 | 32 | 3 |
| js-12 | Три статуси та порядок двох істинних умов | 20 | 3 |
| js-13 | Дужки, важливість, уже завершена задача та рівність ліміту | 24 | 4 |
| js-14 | Позначки для обох значень і збереження пріоритету в картці | 27 | 3 |
| js-15 | Три колонки, невідомий статус і вихід із гілки | 32 | 5 |
| js-16 | Спільна функція пріоритету з числовими аргументами по обидва боки порога | 32 | 2 |
| js-17 | Пропущена, явно передана й нульова тривалість | 32 | 2 |
| js-18 | Порожня і пробільна назва, інший тип і строге повернення null | 32 | 3 |
| js-19 | Формат нульової та дробової тривалості й повторне використання у функції | 32 | 2 |
| js-20 | Два незалежні генератори числових ID і перевірка порядку викликів | 32 | 3 |

Платформа перевіряє поведінку, зокрема виклики функцій на контрольних аргументах. Очікуваний синтаксис пояснено в теорії, завданнях і quiz. Після js-11 набори перевірок уміщують поточну тему та ключові накопичувальні результати в спільний ліміт 32. Окремий браузерний сценарій проганяє еталон js-20 проти всіх наборів 01–19. ## Перевірки

- `npm run build` підтвердив 60 ID, 20 повних пакетів із контрольними сумами і 67 сторінок. Залежності встановлено з lockfile, збірка пройшла на Node.js 26.10.0.
- `npm test` — 73/73 у шести файлах. `npm run lint`, `npm run typecheck` і `git diff --check` пройшли.
- Chromium Playwright 1.65.0. У suite з `reference.author`, `transition.author`, `runner-check.author`, `runner-cumulative.author`, `runner`, `lesson` і `shell` пройшли всі 20 еталонів, 50 негативних сценаріїв нових пакетів і переходи між уроками. Перевірено доступ через prerequisite, невдачу starter, збереження учнівських файлів, завершення, reload і стан на карті. Еталон js-20 пройшов 411 перевірок попередніх уроків у 19 окремих запусках Worker.
- Перша браузерна матриця — 68 passed, 2 skipped та один збій мобільного тесту клавіатурної навігації quiz. Усі шість адресних повторів тесту пройшли. Траса показала активні поля quiz, причина разового збою лишилася невизначеною. Два пропуски стосуються сценарію вузького телефона для desktop і tablet. На mobile він пройшов.
- Незалежне рев’ю підтвердило послідовність матеріалів і перевірило SHA-256 усіх 60 файлів еталонів. Уточнено формулювання quiz js-17 та feedback js-20. Актуальна збірка і два адресні переходи js-17 та js-20 після цих змін пройшли.
- На фінальній збірці пройшла вся мобільна регресія quiz, оболонки та runner — 15/15, включно з клавіатурною навігацією.

## Результат

**P07 прийнято.** Підтверджено 20 накопичувальних контрольних точок, негативні випадки, послідовність навчання та регресію уроків 01–10.

Приймання охоплює поточний локальний курс. Відомі блокери публічного виконання довільного коду описано в [P03_RUNNER.md](P03_RUNNER.md#відомі-межі--блокери-публічного-запуску). Firefox/Safari, повний ручний аудит програм зчитування з екрана та навчання з реальними учнями не входили в цю перевірку.
